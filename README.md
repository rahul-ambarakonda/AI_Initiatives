# AI Initiatives - Project Showcase Platform

A modern, production-ready web application showcasing AI initiatives in Technology Transformation, Digital Engineering, and Quality services. Built with Next.js, featuring a professional design and secure database integration for demo requests.

## 🌟 Features

- **Project Showcase**: Beautiful card-based layout presenting 6 major AI projects
- **Interactive Modals**: Detailed project information displayed in elegant modal dialogs
- **Demo Request System**: Secure form submission with database persistence
- **Database Integration**: SQLite database for storing demo requests
- **Professional UI**: Modern, responsive design
- **Performance Optimized**: Built with Next.js for optimal performance
- **Form Validation**: Client and server-side validation using Zod
- **Accessibility**: WCAG compliant with proper semantic HTML

## 📋 Projects Showcased

1. **Design Document to 3D** - Convert 2D drawings to 3D models using AI
2. **Automated CAD to PDF Conversion** - Multi-stage pipeline for CAD document processing
3. **CodeLens AI** - Full-stack code quality analysis with AI insights
4. **Agentic CAD to Creo** - Automated CAD QA and healing pipeline
5. **Enterprise Document Intelligence** - Centralized document management with AI assistant
6. **Vendor Performance Analytics** - Comprehensive vendor performance dashboard

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/ai-initiatives.git
   ```
2. Navigate to the project directory:
   ```bash
   cd ai-initiatives
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Initialize the database:
    ```bash
    npm run db:init
    ```
5. Start the development server:
    ```bash
    npm run dev
    ```
Open [http://localhost:3000](http://localhost:3000) to view the application.

## 🛠️ Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **Database**: SQLite
- **Validation**: Zod
- **Deployment**: Vercel, Docker
